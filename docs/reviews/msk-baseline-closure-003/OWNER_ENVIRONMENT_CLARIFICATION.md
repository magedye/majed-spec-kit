# مصدر: رسالة المالك الحالية — النص المتاح

وقت الإرسال الأصلي غير متاح؛ هذه نسخة للنص الظاهر في المحادثة، لا ادعاء لهوية بايتات النقل.

ابدأ بالبحث داخل مستودع MSK عن بيئة Python الحالية، وخصوصًا:
D:\APP\maged-spec-kit\majed-spec-kit\.venv\Scripts\python.exe
تحقق من وجود المفسر وصلاحيته وإصداره، ومن توفر الاعتماديات اللازمة مثل pytest وpydantic وtyper وrich وmcp دون تثبيت أي شيء.
إذا وجدت بيئة مناسبة، استخدم مسار المفسر الصريح لتنفيذ الفحوص المصرح بها واستكمال المهمة.
إذا لم توجد بيئة افتراضية مناسبة، يمكنك فحص مفسرات Python الموجودة على الجهاز وتحديد البيئة الأقرب لمتطلبات المشروع، دون تغيير PATH أو إعدادات النظام أو تثبيت حزم جديدة.
إذا كانت الاعتماديات المطلوبة غير متوفرة، سجلها بوصفها مانعًا محددًا (DEPENDENCY_UNAVAILABLE)، وواصل الأعمال المستقلة التي لا تحتاجها.
لا تستخدم بيئة Python تابعة لمشروع آخر لمجرد توفرها، ولا تنشئ بيئة جديدة أو تثبت اعتماديات دون تفويض مستقل.
استمر في تنفيذ MSK-BASELINE-CLOSURE-003 ضمن Write-set والصلاحيات المعتمدة، مع الحفاظ على التغييرات الحالية وعدم تنفيذ Push أو Merge أو البدء في Majed Core.
